🔑 第一步：設定自己的 Gemini 金鑰

每位老師用自己的免費金鑰出題，不會占用別人的額度。申請大約 2 分鐘。

  1. 打開 Google AI Studio 金鑰頁面，用自己的 Google 帳號登入。
  2. 按「Create API key（建立 API 金鑰）」，複製產生的那一串字（通常以 AIza 或 AQ. 開頭）。
  3. 貼到下面，按「儲存並測試」。看到綠色「可以使用」就完成了。

預設用速度最快的 Flash-Lite。如果覺得截圖的文字辨識不夠準、或題目品質想再好一點，可以改選 Flash（比較準，但要等比較久）。

    🛡️ 金鑰安全小提醒

    • 金鑰只存在這台電腦。存在 Chrome 的擴充功能儲存區，不在資料夾裡，所以把擴充套件壓成 ZIP 分享給同事，不會把金鑰送出去。
    • 共用電腦用完要清除。教室、辦公室共用同一個 Chrome 時，下一位使用者也能用到你的金鑰，請按左邊「清除金鑰」。
    • 把金鑰限定只能用 Gemini。到 Google Cloud 憑證頁 編輯金鑰 →「API 限制」選「Generative Language API」。萬一外流也不能拿去用別的服務。
    • 不要截有學生個資的畫面。依 Google 條款，免費方案送出的內容可能被用來改進產品。課本、新聞、繪本內容沒問題，姓名、成績、聯絡資料請不要截。
    • 免費額度有上限。每分鐘、每天能用的次數由 Google 決定，用完會出現「額度用完」，等一下或隔天就恢復。
