# **App Name**: PIRLS QuestionCraft

## Core Features:

- Image Upload: Upload up to four images containing text.
- Text Extraction & Analysis: Uses a tool to scan images, identify text, and extract sentences and paragraphs. After text extraction, analyzes to extract semantic meaning.
- Question Generation: Uses a tool to generate eight multiple-choice questions based on the extracted text, with two questions for each PIRLS reading literacy level (locate & retrieve, make straightforward inferences, interpret & integrate, evaluate & critique). Each question will include four answer choices, with one correct answer indicated.
- Question Display: Displays the generated questions and answer choices, highlighting the correct answer and indicating the source paragraph/location.

## Style Guidelines:

- Primary color: Gentle blue (#75A9FF) to suggest analytical and academic pursuits.
- Background color: Very light, desaturated blue (#F0F5FF) for a clean, readable workspace.
- Accent color: Muted purple (#A387D9) for interactive elements and hints, to catch attention but not distract from the exercise. 
- Clear, legible sans-serif fonts to ensure readability, crucial for comprehension-based exercises.
- Simple, intuitive icons to represent different question types or reading levels.
- Clean, structured layout to separate text, questions, and options clearly.
